# ADR: Accepted risks from the AWS Terraform threat model

Date: 2026-09-27. Status: accepted.
Source: threat model `02909291` (generated by tmi-tf-wh from `terraform/environments/aws-public`),
triaged jointly by the tmi and tmi-mcp agents. Remediation of the "fix" verdicts is tracked
separately; this record covers only what Eric decided to accept and why.

## Human-made architectural decisions (Eric, 2026-09-26/27)

1. **T383, public demo is intentionally ungated: ACCEPT.** `www.tmi.dev` / `api.tmi.dev` is a
   public demo so people can see what TMI does and decide whether it fits them. Sign-in is not
   gated, and every user gets the security-reviewer experience (not admin). Threat models there
   are meant to be public and easy to recreate; Eric keeps JSON exports to re-import a known-good
   state. TMI is open source, so its own threat model is not sensitive. Confidential content
   belongs in threat models marked `is_confidential`.
2. **T374, port-80 egress: ACCEPT.** Scoping DNS egress to the VPC CIDR is still a fix.
3. **T350, the service uses the RDS master credentials: ACCEPT.** The server runs schema
   migrations (GORM `AutoMigrate`) at startup. Eric judged elevated DB credentials in the pod
   the lesser evil compared with giving operators remote DB access to run migrations.
4. **T369 / T360, no WAF: ACCEPT (cost).** API fuzzing (CATS) is relied on instead.
5. **T385, 30-day log retention: ACCEPT (cost).** A hard accept, not a follow-up.
6. **GuardDuty is not adopted (cost).** Not a follow-up item. Consistent with the 2026-09-26
   logging ADR (`2026-09-26-adr-fixed-nat-egress-eip.md`, decision 4).
7. All other "accept" verdicts in the triage stand as triaged.
8. **Added to the remediation plan (not backlog):** TLS for in-cluster Redis and NATS
   (T388, T356 TLS part); HTTPS from the ALB to the pods (T371 / T355); HSTS behind the ALB
   (T370 follow-up); an S3 gateway VPC endpoint.
9. **T379 / T364, no automated secret rotation:** backlog, not accepted; tracked as #965.

## Consequences

- The demo's data is public by design. Anyone with a login can read non-confidential threat
  models; do not put real or sensitive review content on `api.tmi.dev`.
- A compromised server pod has DDL-capable DB credentials. Revisit if the deployment ever
  hosts non-demo data, e.g. by splitting a migration role from the runtime role.
- Without a WAF, request-level attacks are caught only by server-side validation and rate
  limits; the zero-500 and documented-status-code policies carry that load.
- Short retention limits forensic lookback to 30 days.
