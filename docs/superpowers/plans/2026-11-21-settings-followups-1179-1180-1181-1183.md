## Task 1: An invalid explicit row is unusable (#1181)

Decision 9. In `configOutranksRow` / `resolveSetting` (api/settings_service.go), a row that fails `ValidateSettingSemantics` (or the existing per-key semantic validator) counts as no usable row. It follows the same path as `Unreadable` (#1169): the config layer wins, and a Warn log names the key only.

- Compute this at resolution time, consistently, in every caller that shares the table: the typed getters, `GetResolvedString`, and the admin read paths that call `configOutranksRow`. The admin read should report the value in effect.
- `exitOnInvalidEffectiveTimmy` (cmd/server/main.go ~938) becomes log-only for row-sourced values. An invalid env/YAML value still exits (~1929).
- Tests:
  - An explicit row with an invalid `timmy.llm_provider` plus a valid env value: the getter returns the env value, and boot does not exit.
  - Invalid env still exits. Use the existing boot-check test seam.
  - The admin GET shows the config value with the matching source.

## Task 3: The chunk-embed worker follows the effective embedding profile (#1179)

Decisions 6 and 7. Transport only.

- Add an optional embedding-profile field to `pkg/jobenvelope` Job, carrying model, base URL and dimension, never the API key.
- The monolith stamps the effective values at publish time (`api/extraction_publisher.go`, wiring in `wireExtractionNATS`, cmd/server/main.go), read through the settings service so row-wins applies.
- The extractor (`cmd/extractor/handler.go` ~91-98) forwards the field unchanged.
- `cmd/chunkembed`:
  - If the field is present, use its model and base URL. The base URL host must appear in a worker-configured allowlist (new env var, documented, with a sensible empty default that means "only the env base URL's host"). If it does not, fail the job with a clear error that logs the host but no secrets.
  - If the field is absent, fall back to env.
  - Keep one embedder per (model, base URL).
  - On a dimension mismatch between the returned vector length and the stamped dimension, warn and do not fail.
- The worker keeps its API key from Secret `tmi-embedding`.
- Update the worker's deployment config (`deployments/k8s/platform/components/tmi-chunk-embed.yml` and any overlays) for the allowlist env var. Leave the egress policy unchanged.
- Update `sharedEmbeddingClass` / `StampedIntoEnvelope` comments and stamped_config_provider docs so they match the implementation.
- Tests:
  - envelope round-trip, including old envelopes that lack the field;
  - the publisher stamps effective (row-wins) values;
  - the extractor forwards the field;
  - the worker follows an allowlisted URL, rejects a non-allowlisted one, and falls back to env;
  - the dimension warning.
- Rollout note in the report: workers first, then the extractor, then the monolith.
